Privacy Policy — Overlay MatchTimer

Last updated: 2026-11-13 · Developer: Vasco Oliveira

Summary

Overlay MatchTimer does not collect, sell, or send personal data to a developer-operated server. It runs locally in Chrome to overlay a match clock and controls on supported video pages.

Data stored on your device

Preferences may be stored in Chrome local extension storage and mirrored in page localStorage where the content script runs:

  • Match clock position, size, and style
  • Custom keyboard shortcuts
  • ShuttleXpress skips, Play/Pause assignment, jog/ring settings
  • Popup section open-state and per-window Shuttle enable flag
  • Optional kickoff-sync settings (enable flag, project URL, anon key, room id) — off by default

This data stays on the machine/profile that installed the extension unless you enable kickoff sync.

Data we do not collect

  • No analytics SDKs or advertising identifiers
  • No developer-backend account login
  • No transmission of video, keystrokes, or preferences to an Overlay MatchTimer server

Optional kickoff sync (default off)

From v1.7.0, Customize may offer Kickoff sync. It stays off by default. While off, the extension makes no sync network requests. If you enable it and enter your own Supabase project URL and anon key, kickoff / clock-reference values for a match room may be sent to and read from that project. Optional host access to https://*.supabase.co/* is requested only when enabling.

Third parties

Video comes from InplayIP / Examino / local files under your existing access. This extension does not share additional data with those services. Optional sync talks only to the Supabase project URL you configure.

Host access

Scripts inject on declared hosts: InplayIP, Examino play URLs, and localhost/127.0.0.1 for local player / test pages. Optional Supabase host permission is requested only when kickoff sync is turned on.

Changes

Material privacy changes will update this page and the date above.
