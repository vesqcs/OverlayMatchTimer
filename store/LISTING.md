## Detailed description (English)

Overlay MatchTimer is a Stats Perform operations tool for match video review. It injects a configurable match clock and transport HUD over supported InplayIP and Examino DVR/VOD pages, and includes a local player window for offline or NAS-mapped files.

**What you can do**
- Show a match clock (mm:ss) in six on-screen positions, four sizes, and Box / Pill / transparent styles
- Click the clock to type a time (flexible separators); invalid seconds stay editable with a clear hint
- Use keyboard shortcuts for play/pause, skips, frame step, speed, kick-off, live, and hide controls — all rebindable in the popup
- Pair a Contour ShuttleXpress (WebHID) per browser window: five buttons, jog, and shuttle ring, with skips and Play/Pause assignable in Customize
- Optional “auto pause on Alt+Tab” (off by default); never applied on pages where ShuttleXpress is enabled
- Open a dedicated local player from the popup for file-based analysis

**Who it is for**
Internal Stats Perform / RunningBall workflows that already use InplayIP and Examino. This listing is intended to be **Unlisted** (link-only), not a public consumer product.

**Privacy**
The extension does not collect, sell, or transmit personal data to a developer backend. Preferences stay in Chrome’s local extension storage on your machine. See the privacy policy included with this package.

**Permissions (summary)**
- `storage` — save clock, shortcut, and Shuttle preferences on this browser
- Host access only to InplayIP, Examino, and local test URLs so the overlay can run on those pages

Adds a match-clock overlay and optional ShuttleXpress controls on InplayIP/Examino match video pages and a local file player for offline analysis.
