## Video-error banner audit (Vasco)

**Original HTML** (`OverlayMatchTimer.html`) had a user-facing `#error-banner` / `mostrarErro()` for pasted-stream failures (expired DVR/Xeatre URL, fatal HLS, native `video` error). That UI was for the tool that *owned* playback via a pasted link.

**Extension (InPlay / Examino / Xeatre):** That banner was **never ported**. There is no `#error-banner`, no `mostrarErro`, and no `vid`/`error` listener that shows a stream-error overlay on site pages. Site adapters only attach to the host player (hooks / PDT / observers) — they do not surface a video-problem message. **No code removed** (nothing to remove).

**Local player:** No error banner either. On reject (non-video type / bad extension) it shows a brief OSD: `Unsupported file`. A failed `play()` after load is silently caught; there is no “can’t play this file” media-error overlay today. Left as-is (fine to keep a simple can’t-play OSD later if wanted).
