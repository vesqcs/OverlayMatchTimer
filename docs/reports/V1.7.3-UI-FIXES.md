# v1.7.3 — UI fixes (Vasco laptop feedback)

## Changes (redesign UI only)

1. **Customize Shuttle diagram hit areas** — invisible filled targets + `pointer-events: all` on jog disc / ring band / button wedges; labels/nums never steal clicks.
2. **More panel expands up** — `#omt-more-panel` is `position: absolute; bottom: calc(100% + …)` so the main control bar stays pixel-fixed; extras overlay above.
3. **LIVE hidden on local player only** — `#omt-root.omt-local #omt-live-btn` / spacer `display: none`; streams unchanged.
4. **Eye button → Auto hide toggle** — ON = Lucide `eye-off` + tip `Auto hide: on`; OFF = `eye` + `Auto hide: off`. Persists `omtAutoHideChrome` (default ON). Gates existing `resetControlsTimeout` idle fade; does **not** hide immediately.

## Original mechanisms left alone

- Player hooks, PDT, observers, SPA intervals, adapters untouched.
- Auto-hide **timer body** reused; only gated when preference is OFF.
- **H hotkey** still calls `toggleManualControlsVisibility()` (hide/show chrome completely). The eye button no longer mirrors H.

## Note on “hide panel completely”

Removing that action from the eye button does **not** remove the original capability: **H** (and the Customize shortcut binding for Hide/Show Controls) still hide and restore the panel. Report this if analysts relied on the eye icon specifically rather than H.
