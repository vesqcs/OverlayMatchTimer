**Date:** 17 Nov 2026  
**Branch:** `cursor/v210-xeatre-adapter-ccd4` (stacked on v2.0.5 / PR #16). Do not merge until signed off.

## Goal

New **isolated** site adapter for Stats Perform Xeatre / Global Media Manager DVR popup (`Videoplayer`). Our match clock, timeline, control panel, hotkeys, and ShuttleXpress attach to the Xeatre `<video>`. **All host chrome is hidden** (Vasco correction): 6-column DOC/FRAME/PLAY-PAUSE/LIVE/FULL panel (docked + floating + Auto hide) and the native bottom bar. Analysts use OMT controls only.

## Design

- Adapter `SITE_XEATRE`: find `.vjs-tech` / `.video-js video`; always review/DVR; duration via finite `duration` or seekable end (Wowza often Infinity).
- Timeline LIVE mode: default live path (same as other non-local DVR hosts) — delay / LIVE chip via existing `omtIsTimelineLiveMode` / PDT helpers; no change to Examino/InPlay mechanisms.
- Hide: scoped `html.omt-host-xeatre.omt-hud-on` CSS + sticky class on non-media panel nodes. **Never** hide `.video-js` / video ancestors. **Never** `window.postMessage` (2.0.5 lesson — bus stays CustomEvent).
- Our panel already covers play/pause, skips, speed, LIVE jump, fullscreen.
