## Field (2.2.8)

Before HUD: `#hdmi-video` 720×405, `video.vjs-tech` 720×405. After `hudOn` / hide-chrome: `#hdmi-video` `display:none` / 0×0 (audio still plays).

Also: `VIDEOJS WARN: Player "hdmi-video" is already initialised` and host `play()` `NotAllowedError`.

## Root cause

Bare CSS `#ControlBar { display:none }` hid a **wrapper** that contains `#hdmi-video` on the real dvrplayer page. Child size collapses to 0×0.

## Fix (Xeatre only)

1. Hide `#ControlBar` / panels only with `:not(:has(#hdmi-video)):not(:has(video))…`
2. Force `display:block` on `#hdmi-video` / `.video-js` / tech (not just visibility)
3. `findAnchor` walks past wrapping `#ControlBar` so HUD is not mounted under hidden chrome
4. Do not attribute-mutate tech/shell (no tabindex) — avoids host re-`videojs('hdmi-video')`
5. Never call `videojs()`; `safePlay` always catches rejects; on Xeatre skip speculative `play()` until a user gesture
