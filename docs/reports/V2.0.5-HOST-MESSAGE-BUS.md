# v2.0.5 – Examino play/pause loop (host message bus)

**Date:** 17 Nov 2026  
**Branch:** `cursor/v205-vod-live-loop-ccd4` (stacked on v2.0.4 / PR #15). Do not merge until signed off.

## Field evidence

- 2.0.4 ON, Examino `/play/dvr/`: play/pause/waiting storm; sticky hide ruled out.
- MAIN-world wraps: **strictly alternating pause/play, no `currentTime` seeks**.
- Stacks: host Svelte chunk `BIyTHCyh.js` function **D** (caller is the `window` `message` listener).
- **Same PC / Chrome 157: v1.2.0 (`811be7b`) works** — auto-VOD, no AbortErrors, no churn. Chrome is not the cause.

## Root cause (exact culprit)

**Culprit:** `omtClearLegacyClockCustom()` ↔ expanded `bridge.js` storage sync, carried on `window.postMessage`, which Examino’s Shuttle button-bar interprets as play/pause.

### Host side (unchanged; field chunk)

```js
window.addEventListener("message", e => {
  if (e.data.type === "forcedFocus") return g(e.data.value);
  e.origin === window.location.origin &&
    (e.data.isKeyPressed || D({ target: { title: J[e.data.key] } }));
});
// D: missing/unknown title → s.paused !== undefined → always toggle play/pause
```

### Our side (regression vs 1.2.0)

| 1.2.0 | 2.0.4 |
| --- | --- |
| `bridge.js` syncs **only** `omtAutoSwitchVod` | Bridge syncs customize / shuttle / panel / sync keys (defaults include `omtClockCustomOffset: null`) |
| MAIN world posts `OMT_STORAGE_SET` only when the user toggles auto-VOD | Two writeback amplifiers on every sync: **`omtClearLegacyClockCustom()`** → `OMT_STORAGE_SET(null)`, and **`cleanupShuttle()`** → `storageSetShuttleEnabled(false)` whenever sync repeats `shuttle:false` |
| No MAIN listener that re-applies customize / shuttle teardown on every sync | Sync → SET → `onChanged` → sync → **tight `window.postMessage` storm** |

Each storm message is same-origin without a Shuttle `key` / `isKeyPressed` → host **D** toggles. That matches the field stacks (no seeks) and why 1.2.0 is fine on the same Chrome.

**Named culprit:** post-1.2.0 storage-bridge writeback loop (`omtClearLegacyClockCustom` + `cleanupShuttle`/`storageSet*` on unchanged values) emitted on `window.postMessage`, consumed by Examino `BIyTHCyh.js` function `D`.

Not caused by timeline live-edge, decode re-assert, auto-VOD itself, or sticky hide (2.0.2–2.0.4).

## Fix

1. **Stop emitting OMT traffic on `window.postMessage`.** Page ↔ bridge uses `omt-bridge-bus` CustomEvent (`src/bus.js` + `bridge.js`). Host `message` listener never sees it.
2. **Break the writeback loops:** one-shot `omtClearLegacyClockCustom`; `storageSet*` no-ops when unchanged; shuttle sync only tears down on true→false and uses `cleanupShuttle({ skipStorage: true })`.
3. Keep 1.2.0 Source/speed fixes (Source scrape/apply, speed menu separation) — they do not use the message bus for media control.
