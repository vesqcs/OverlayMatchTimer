# v2.2.15 – Visibility-only pause + Xeatre rect click

**Date:** 20 Nov 2026  
**Branch:** `cursor/v235-visibility-xeatre-click-ccd4` (stacked on v2.2.14 / PR #36). Do not merge until signed off.

## Root causes

### 1) Alt-tab / focus regression (2.2.14)

Default pause listened to **window blur**, so clicking the collection program beside a visible player paused video. Shuttle “top” video likewise paused on focus loss.

**Fix:** pause/resume only on `document.visibilitychange` (`hidden` / `visible`). **No blur/focus handlers.** Visible-but-unfocused windows always keep playing. Setting **Keep playing on alt tab** (`omtKeepPlayingOnAltTab`) ON still never pauses on hide and undoes Examino’s native hidden pause via one microtask `play()`.

**Cost:** still zero ongoing work — only once-registered `visibilitychange` listeners; no intervals/timeouts/observers for this path. InPlay seek/player untouched.

### 2) Xeatre click (2.2.14)

Vasco field probe (top frame, 1 video, 0 iframes): click target is `DIV#videowrapper`; `elementsFromPoint` = `videowrapper | BODY | HTML`. `VIDEO#hdmi-video_html5_api.vjs-tech` inside `DIV#hdmi-video.video-js` is **not** in the hit stack (`pointer-events: none` on shell/tech from VJS/host — **not** from our chrome-hide rules, which only set PE none on chrome leaves).

Harness previously clicked the `<video>` directly, so tests passed while the field failed.

**Fix:** window capture `pointerdown`/`pointerup`/`click`; treat primary-button pointerup with small movement whose point lies in `video.getBoundingClientRect()` as a video click **regardless of `event.target`**; exclude OMT panel/bar/timer and visible Xeatre controls; `stopImmediatePropagation` once. Also force `pointer-events: auto` on the media shell in HUD-on CSS (optional restore; rect hit-test is authoritative).

### 3) hide-chrome debug spam

`[OMT-DEBUG][xeatre] hide-chrome` ran on every MutationObserver chrome pass (VJS user-active thrash). Now gated behind `localStorage.omtDebugXeatre='true'` / `window.__OMT_DEBUG_XEATRE`.

### 4) Setting label

English UI: **Keep playing on alt tab** (storage key unchanged: `omtKeepPlayingOnAltTab`).
