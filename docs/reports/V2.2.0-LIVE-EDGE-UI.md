## Tunable constant

```js
OMT_LIVE_SAFE_MARGIN_S = 10   // base
OMT_LIVE_SAFE_MARGIN_MIN_S = 4
OMT_LIVE_SAFE_MARGIN_MAX_S = 30
```

Used as:

- **Counts as LIVE** (panel LIVE red / timeline chip enter): delay ≤ base (10 s).
- **LIVE jump floor after a recent stall**: never closer than base.
- **Adaptive LIVE jump** (no visible seek-bar marker):

| Stream state | Margin |
| --- | --- |
| Recent `waiting`/`stalled` | `max(base, ~2 edge updates, ~2× targetDuration)` |
| Slow edge / long segments / thin buffer | same as above (≥ base) |
| Stable (healthy buffer, short/fast edge, no recent stall) | may go closer than base, down to `MIN` |

Edge cadence is measured from seekable-end advances (median interval of recent moves). Field note (unstable Examino): jumping to raw edge / −3 s stalls when the edge updates slowly — stay ≥ ~2 updates behind.

**No visible safe-point marker** on the seek bar (dropped per Vasco). Manual skips are never clamped.

## Segment length note

Typical HLS `targetDuration` is 2–6 s → base 10 s ≈ 2–5 segments (safe). If a stream’s segment length approaches or exceeds the base, adaptive margin grows via `2× targetDuration` / edge cadence (capped at `MAX`).
