## Single source of truth

`omtResolveLivePresentation()` → `{ liveMode, kickoffOn, playhead, liveEdge, delay, atLive }`

| Piece | Driven by |
| --- | --- |
| Panel `#omt-live-btn.is-live` | `snap.atLive` |
| Timeline LIVE chip vs `-0:12` delay | `snap.atLive` (mutually exclusive) |
| Scrubber / panel `omt-at-live` | `snap.atLive` |
| Right `playhead / furthest` | `snap.liveMode` (hidden when not live) |
| Left POST `current / duration` | `!snap.liveMode && !kickoff` |
| Left match clock | `snap.kickoffOn` |

**atLive enter:** delay ≤ adaptive safe margin + `OMT_LIVE_AT_LIVE_TOL_S` (1.5s)  
**atLive leave:** delay > enter + 5s (shared latch — panel and chip never disagree)  
**LIVE jump:** `irParaLive` → seek → `atualizarEstadoLive({ forceAtLive: true })` (same snapshot paints everything).
