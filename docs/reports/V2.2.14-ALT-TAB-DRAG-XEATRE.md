## Alt-tab cost (hard constraint)

**Confirmed: no `setInterval`, no `setTimeout`, no `MutationObserver` / `IntersectionObserver` / `ResizeObserver` added for alt-tab.**

`src/auto-pause.js` registers once:

- `visibilitychange` (capture + bubble)
- `blur` (capture + bubble)
- `focus`

Event handlers may call one-shot `pause()` / `play()` (keep-playing uses `queueMicrotask(play)` after a host `pause` event). No polling while the tab is visible. InPlay seek/player code unchanged.

## Root causes

1. **Panel stuck to mouse (2.2.12):** `#omt-root` swallowed `mouseup`, so `document.onmouseup` / drag end never ran. Fix: swallow only `click`/`dblclick`; end drag on window capture `pointerup`/`mouseup`.
2. **Xeatre field click:** VJS often eats `click` after `pointerdown`; `safePlay` could no-op. Fix: toggle on `pointerup` with direct `play()`, ignore following click.
3. **Alt-tab:** old “Auto pause on Alt+Tab” default OFF left Examino host pause in place; keep-playing needed a uniform, zero-cost path across all hosts.
