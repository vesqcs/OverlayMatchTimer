# v1.7.6 — Period ticks + edge-safe tooltips

## Timeline

- **At rest:** no period markers or labels.
- **On hover:** thin subtle ticks at each kick-off with tiny grey short labels **below** the track (`1st` / `2nd` / `ET1` / `ET2` / `Pen`).
- **One tip above:** `period · match clock` (e.g. `1st Half · 23:41`; `Pre-match` before kick-off). Same dark tip chrome as controls; subtle fade-in.
- **Snap (~8px):** tip locks to the tick, tick turns orange, click seeks to that period start.
- Tip never overlaps tick labels (above vs below). Redesign UI only.

## Tooltips

- Horizontal edge-clamp (`--omt-tip-shift`) inside the floating card / `#omt-root`.
- More panel `overflow: visible` when open so tips escape.
- Shortened copy (Open file → `Open local or NAS video`, Shuttle, Period, Kick-off, offsets, Source, Auto VOD).
- Red X → **`Clear timer`** (`limparTimer`: all kick-offs + offsets + hide clock).
