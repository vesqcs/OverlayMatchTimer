## Bottom bar (all sites, UI only)

When kickoff/match clock is set, **do not** show match clock at bottom-left of our bar (already on clock panel + scrubber tip).

| State | Panel LIVE | Bottom-left | Bottom-right `playhead / furthest` |
| --- | --- | --- | --- |
| Live, no kickoff, at live | Red | LIVE chip | Shown |
| Live, no kickoff, behind | Grey | Delay e.g. `-0:12` | Shown |
| Live + kickoff, at live | Red | LIVE chip only (no match clock) | Shown |
| Live + kickoff, behind | Grey | Delay only (no match clock) | Shown |
| VOD / post / local | Grey | `current / duration` | Hidden |
| Post + kickoff | Grey | `current / duration` (no match clock) | Hidden |
