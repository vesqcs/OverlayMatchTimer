## Field (2.2.10)

1. Shrinking the dvrplayer popup scales the HUD down; growing again left a sticky tiny panel until click — inline `transform: scale(...)` from the fit path was never cleared.
2. With the fixed HUD, moving the pointer over the video no longer revealed panel/bar (listeners/targets missed through letterbox / overlays).

## Fix (Xeatre only, our layer)

1. Micro/compact via CSS classes only; use independent CSS `scale` so it multiplies on top of user panel size/compact prefs (no width override).
2. On leave micro (grow): clear leftover panel inline fit props and re-apply `omtApplyPanelAppearance` — restore without a click.
3. Recompute on `resize`, `ResizeObserver`, `fullscreenchange` (rAF-debounced).
4. Document `pointermove` / `mousemove` on Xeatre reveals chrome; idle auto-hide unchanged.
