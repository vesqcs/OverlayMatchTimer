## Field root cause

`apply:option-not-found` searched for `opDataValue === "DVR"`. Real OpenPlayer Source panel mixes:

| Row | opPanelType | hasNext | opDataValue | title |
| --- | --- | --- | --- | --- |
| Speed | speed | true | `1x` | Speed |
| Source (current) | source | true | `VOD(1)` | Source |
| Quality | quality | true | `1920x1080…` | Quality |
| **DVR leaf** | source | **false** | **`0`** | **DVR** |
| **VOD leaf** | source | **false** | **`1`** | **VOD(1)** |

## Fix

- Source **options** = `opPanelType === "source"` AND `hasNext === false`
- Match by **title** prefix (`DVR…` / `VOD…`); click by index `opDataValue`
- **Current** source = top Source row (`hasNext === true`) `opDataValue` (label string)
- Confirm by re-reading that top-row label/kind — never by `mediaUrl` (always null on MSE)
- Soft confirm after `apply:success` if needed
- All `[OMT-DEBUG][examino-source]` lines are `JSON.stringify` strings
