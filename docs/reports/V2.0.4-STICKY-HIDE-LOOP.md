# v2.0.4 – Examino play/pause loop (sticky hide) + InPlay CPU

**Date:** 17 Nov 2026  
**Branch:** `cursor/v204-play-pause-loop-ccd4` (stacked on v2.0.3 / PR #14). Do not merge until signed off.

## Field evidence

- Examino `/play/dvr/` with 2.0.3 ON, 10 s: **play 7026 / pause 7026 / waiting 6347** on one `<video>`. Console: `play() interrupted by pause()` and **video-only background media was paused to save power** (from the host player script).
- Same page, extension OFF: video fine, **no** AbortError storm.
- InPlay `/schedule` with 2.0.3 ON: **zero** play/pause/waiting in 10 s. Slowness is CPU/layout, not a media loop.

## Root cause (Examino)

Not double injection and not two players. Same class of bug as 2.0.2:

1. On Source DVR↔VOD, OpenPlayer briefly removes `<video>`.
2. Our native-chrome hider runs in that gap. The LIVE/FOCUS/seek heuristic can stamp `omt-examino-native-hidden` on **`.op-player` itself** (`querySelector('.op-player')` does not match the element it is called on).
3. The class was **sticky**: when the new `<video>` remounted inside that node, the class was never cleared. CSS still applied `display: none` to the media host.
4. Chrome power-save paused the hidden video; OpenPlayer kept calling `play()` → hundreds of play/pause pairs per second.

We do not have a pause→play handler of our own; the host does the `play()` half.

## Fixes

1. **Refuse media hosts** in `markNativeHidden` (including `.op-player` / `.video-container` / `.main-container` / `.top` as the element itself).
2. **Scrub** `omt-examino-native-hidden` from any media host at the start of every hide pass.
3. **CSS safety belt:** the sticky-class rule uses `:not(:has(video))` (and friends) so it **stops applying** as soon as a `<video>` is back inside the node — even if the class lingers.
4. **Singleton guard:** `window.__OMT_MAIN_LOADED__` aborts a duplicate MAIN-world inject.
5. **InPlay CPU:** scope all Examino `:has()` hide rules under `html.omt-host-examino` so InPlay’s heavy `/schedule` DOM does not pay those style matches; stop using `document.body.innerText` in `isLiveStream()` (scan player chrome only).

Original mechanisms (player hooks, time/PDT, adapters, ShuttleXpress) unchanged.
