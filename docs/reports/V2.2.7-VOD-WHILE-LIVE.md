# v2.2.7 – VOD-while-live uses live bar chrome

**Date:** 19 Nov 2026  
**Branch:** `cursor/v227-vod-while-live-ccd4` (stacked on v2.2.6 / PR #28). Do not merge until signed off.

## Field bug (Examino Auto VOD)

On DVR the bottom bar was correct (delay/LIVE left, `playhead / furthest` right). After Auto VOD while the match was **still live**, the bar fell back to post layout: left `current / duration`, nothing on the right. LIVE button / chip / red state also stayed in post mode.

## Fix (UI gating only)

`omtIsTimelineLiveMode()` (shared PDT):

| Page / source | Mode |
| --- | --- |
| Examino `/play/dvr` (any Source, incl. Auto VOD) | **live** |
| Examino `/play/vod` (true post-match) | **post** |
| Examino fixture / unknown path + Source VOD | **post** |
| Local player | **post** |
| InPlay / Xeatre | unchanged (always live on those hosts) |

No changes to DVR↔VOD Source switching, Examino apply/confirm, or InPlay player code.

## E2E

- `live-consistency-vod-while-live` — `/play/dvr` + Source VOD → delay + range behind; LIVE click → red + chip + range
- `live-consistency-vod-post` — now uses `/play/vod` for true post-match
