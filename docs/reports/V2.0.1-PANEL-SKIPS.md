# v2.0.1 - Control panel, skips, timeline chrome, packaging

**Date:** 16 Nov 2026  
**Branch / PR:** `cursor/v201-panel-skips-ccd4` (PR #13), stacked on v2.0.0  
**Scope:** UI / Customize / packaging docs only. No player hooks, PDT/time reading, adapters, or ShuttleXpress device handling changes. Layout observers for video surface visibility only (no time reads).

## Changes

1. **Local player drop zone**  
   Copy: `Drop or browse a match video file, local or from the NAS.` Hint uses a comma (no dash). Tab title: `Overlay MatchTimer`.

2. **Control panel size**  
   Customize: **M** (default, current look) / **S** (smaller). **Compact** (default off) hides the lower speed-chip row; top speed select stays.

3. **Skip seconds in Shortcuts**  
   Each skip back/forward row has a seconds input (**1 to 999**, defaults **2 / 10 / 120**) plus reset, Shuttle-style. Labels and General list show live amounts. Panel buttons auto-sort by value (smallest next to play). Keyboard maps to each row’s value. ShuttleXpress Btn 1 to 5 times stay separate.

4. **Popup logo**  
   No hover tooltip on the brand mark.

5. **Video surface visibility**  
   Generic guard (`IntersectionObserver` + `ResizeObserver` + rect / optional `elementFromPoint`): hide `#omt-root` when the video is collapsed, offscreen, or covered (InPlay Review curtain). Does not change how video time is read.

6. **Fullscreen**  
   Enter/exit control on the timeline chrome row; icon toggles; overlay reparents into `document.fullscreenElement` when needed.

7. **Host CSS isolation**  
   Overlay tokens and px font metrics on `#omt-root` so host `html{font-size}` / button resets cannot shrink the HUD. Accent colours (Kick-off orange, active speed, playing pause, LIVE chip) locked with `#omt-root … !important` against host `button { background/color/filter }` greys.

8. **Timeline chrome (YouTube-style layout)**  
   Full-width scrubber on top; slim chrome row below (volume + time left, fullscreen right). Visibility follows the control panel (existing auto-hide). Time text:
   - Kickoff set → match clock only
   - Live, no kickoff → delay / red `LIVE` chip (`#e5383b`, enter within about 10 s, leave after about 15 s)
   - Post, no kickoff → `current / duration`  
   Timeline volume stays in sync with panel volume. Hover tip unchanged. No change to time/PDT reading.

9. **Runtime-only packaging**  
   `scripts/pack-extension-zip.sh` ships only the Chrome runtime allowlist (no `src/`, `scripts/`, `design/`, `package.json`, `vendor/`). Full owner/QA bundle: `OverlayMatchTimer-v2.0.1-full.zip` with docs + runtime folder + nested clean extension zip.
