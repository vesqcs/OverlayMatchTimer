# v2.0.1 — Control panel size, Compact, custom skip times

**Date:** 15 Nov 2026  
**Scope:** UI / Customize only. No player hooks, PDT/time reading, observers, intervals, adapters, or ShuttleXpress device handling changes.

## Changes

1. **Local player drop zone** — copy: `Drop or browse a match video file, local or from the NAS.`; hint uses a comma (no dash). Tab title: `Overlay MatchTimer`.
2. **Control panel size** — Customize: M (default, current look) / S (smaller). **Compact** (default off) hides the lower speed-chip row; top speed select stays.
3. **Skip times** — Customize: short / medium / long in whole seconds (1–999), defaults 2 / 10 / 120, with Reset. Same values drive panel skip buttons and matching keyboard / ShuttleXpress skip bindings (constants swapped for settings only). Panel labels: under 60 → `N s`; 60+ → minutes (`2 min`, `1:30 min`).
