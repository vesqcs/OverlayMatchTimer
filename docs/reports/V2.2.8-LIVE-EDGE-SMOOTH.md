## Field bug

Examino seekable end advances in ~10s playlist steps. After each refresh the delay jumps, the playhead falls past the old at-live leave band (`enter + 5`), and the LIVE button flickers grey → red → grey. Displayed delay / furthest also stair-step.

## Fix

1. **Observe step** — record seekable-end jump sizes; median (else HLS target / default 10s).
2. **Leave band (Examino)** — stay at live while `delay ≤ safeMargin + observedStep + 2s` (and at least `enter + 5`). Drop immediately only on a clear seek-back (`delay > leave + step`); otherwise require ~1.2s sustained overrun.
3. **Smooth presentation edge (Examino)** — between refreshes, `edge ≈ lastEdge + elapsed × (step/interval)` clamped to the next expected step. Button, chip, delay text and furthest share this one edge. **Seek / safe-point still use raw seekable end** (no auto-seek past media).
