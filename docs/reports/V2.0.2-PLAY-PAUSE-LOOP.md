# v2.0.2 - Examino play/pause loop and InPlay HUD-off controls

**Date:** 17 Nov 2026  
**Branch / PR:** `cursor/v201-panel-skips-ccd4` (PR #13)  
**Scope:** Fix field regressions from v2.0.1. No change to PDT/time reading, adapters’ seek hooks, or ShuttleXpress device handling.

## Field evidence (Vasco)

- Examino DVR with extension ON, 10 s on the page video: `{pause:2494, play:2494, waiting:2043}` (~250 pairs/s). Chrome: `AbortError: play() interrupted by pause()` and power-save pause for “video-only background media”.
- Same page with extension OFF, 10 s: `{}` (zero play/pause). Confirms the extension caused the loop.
- InPlay: no AbortErrors; Video.js buffer goals thrashing; sometimes no controls and curtain hard to use when our HUD was hidden while native chrome stayed suppressed.

## Root cause (plain words)

Our Examino hide-CSS used `.op-ui:not(.op-media-element-container) { display: none }`. On real Examino, `.op-ui` often **wraps** the media container and `<video>`. Hiding that node made the video `display: none`. Chrome then paused it to save power; OpenPlayer kept calling `play()`; Chrome paused again. That fight ran as a tight play/pause loop (hundreds per second). We did not have a `pause` → `play` handler of our own; the host player’s resume logic did the `play()` half.

InPlay “no controls” came from the v2.0.1 visibility guard hiding `#omt-root` while global CSS still hid Video.js chrome. Overlay children with `pointer-events: auto` could also keep eating clicks while the root was only `visibility: hidden`.

## What changed in 2.0.2

1. **Never hide a node that contains the video** — CSS `:not(:has(video)):not(:has(.op-media-element-container))` on `.op-ui`, and the same rule in injected Examino hide CSS. `markNativeHidden` also refuses media ancestors.
2. **Visibility guard softened (InPlay + Examino)** — removed `elementFromPoint`; **removed ResizeObserver on the video** (showing/hiding `#omt-root` was feeding RO → layout → RO CPU storms and slow curtains); size hysteresis; 150 ms debounce; bubble scroll only; tear down cleanly; when obscured, clear `html.omt-hud-on` so host chrome can show; `#omt-root.omt-video-obscured` uses `display: none` and forces descendants to `pointer-events: none`.
3. Host chrome hide rules gated on `html.omt-hud-on` (InPlay + Examino).
4. Version bump to **2.0.2**. Regression tests: Examino idle play/pause, nested `.op-ui` keeps video visible, InPlay 10 s CPU/loop guard (play/pause + visibility schedule/apply counts), snappy curtain toggle, curtain restores host bar, centre cover does not hide HUD.

## Chrome / MV3 note

Manifest V3 is fine. Nothing here points to a Chrome update breaking a healthy 2.0.0 build by itself. The loop needs our hide-CSS to blank the media; with the extension disabled there are zero play/pause events on the same Chrome.
