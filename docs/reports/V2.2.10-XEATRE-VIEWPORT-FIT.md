## Field (2.2.9)

Video paints, but resizing the dvrplayer popup breaks layout: `.vjs-fluid` height = width×9/16 via `padding-top`, ignores window height → document overflow/scroll. `#omt-root` was `position:absolute` inside the player, so the panel/bar scrolled off-screen.

## Fix (Xeatre only, our layer)

1. `html/body` `overflow:hidden`, fill viewport
2. Kill `.vjs-fluid` padding-top; size `#hdmi-video` / `#ControlBar` to **contain** 16:9 in the window (letterbox)
3. `#omt-root.omt-xeatre` → `position:fixed; inset:0` (panel + bar always on-screen)
4. Compact / micro scale when the popup is small
5. Recompute on `resize` + `fullscreenchange`
