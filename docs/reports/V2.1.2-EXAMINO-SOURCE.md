## A. Examino Source / VOD (2.1.1 field)

### Evidence

- Overlay Source → VOD snaps back to DVR; OSD “Source change failed”. Auto VOD ON/OFF same. Extension OFF gear→VOD works.
- URL stays `/play/dvr/…` after gear→VOD on real Examino.

### Cause vs v1.2.0

| Step | v1.2.0 | 2.1.1 |
| --- | --- | --- |
| After clicking VOD option | `sleep(250)`, return **true** | Wait for Source row re-label → often **false** |
| Tear down settings UI | Remove raised + temp-visible only | Also stripped host **`.open`** |
| On “failed” | OSD only | `refreshExaminoSourceSelect()` → path `/play/dvr/` → overlay **forced to DVR** |

### Fix (Examino-only: `src/examino-features.js`)

1. Apply like v1.2.0: option click → settle → success; never strip host `.open`.
2. On failure: never refresh/fill back to DVR; keep user selection.
3. Prefer last-applied / manual over URL path.
4. `[OMT-DEBUG][examino-source] …` on every reveal / scrape / apply / fill / UI-change step.

## B. InPlay close-X freeze (confirmed ours)

### Evidence

- `inplayip.tv/schedule`, 2.1.1: every click on the round black **✕** (top centre, under the curtain arrow) → Chrome “page unresponsive”, then video exits.
- **Extension disabled: close-X does not freeze.** So this is our code.

### Cause

When the `<video>` disappears, SPA did `teardown()` + `boot()`. `boot()` attached a **document-wide `MutationObserver`**. Close-X dismantles the Video.js tree (hundreds of nodes). Each mutation batch re-entered mode detection; `isLiveStream()` read **`.players-container.innerText`**, forcing full layout on a huge DOM → main-thread freeze.

Click handlers / Examino click-to-toggle are **not** on this path (InPlay uses video-surface click only; ✕ is a host button and stays host-hittable under stacking isolation).

### Fix (InPlay-scoped)

| File | Change |
| --- | --- |
| `src/adapters/inplayip.js` | `isLiveStream()`: **selectors only** — remove `innerText` |
| `src/boot.js` | On InPlay video-gone: quiet idle **poll** (`startSPAMonitor`) — **do not** `boot()`→MutationObserver during host teardown; 4s quiet window; debounce any cold-start InPlay MO (250ms) |

No Examino/Xeatre/shared UI/bus changes for this fix beyond the InPlay branches above.

### What 2.1.0 / 2.1.1 changed for InPlay vs 2.0.5

| Area | Diff | Notes |
| --- | --- | --- |
| `inplayip.js` | No behaviour change in 2.1.0/2.1.1 | Freeze path was **pre-existing** SPA+MO+innerText (innerText moved from `body`→`players-container` in 2.0.4) |
| `content.css` InPlay rules | Byte-identical | Xeatre/Examino blocks only added |
| `boot.js` / `entry.js` | Xeatre-gated only | Did not introduce the close-X loop; 2.1.2 fixes the InPlay idle path |

Vasco’s “every close-X” repro + extension-off control prove we must fix it here even though 2.1.x did not newly author the loop.
